Governing philosophy (from the Sport-project method) — read this before designing Phase 2 This is the architectural shift that must inform Phase 2. It directly contradictshow the old Maxona planner worked, and that contradiction is *why* the old plannerfelt dumb: - **No rigid rule-engine with hard pass/fail branches.** Metrics (EF, decoupling,  zone share, etc.) are computed deterministically in code. But the actual judgment  call on what the plan should look like stays with the LLM, given full context —  not a hardcoded decision tree.- **Session count per week is negotiated fresh each week**, not a fixed constant.  The athlete and the planner agree on how many sessions fit before the plan is  generated in detail.- **A real safety fallback ("stop now") is wanted** — but its trigger pattern must  be built empirically from *this athlete's own history*, not imported from generic  sports-science thresholds. He has trained at HR ~170 as his personal normal for  years and almost never bonks from physiological limits — his actual failure modes  are fueling failures and pre-day alcohol, not HR-ceiling breaches. A safety  pattern copied from a textbook would be miscalibrated for him specifically.- **Ordinary training sessions get descriptive, post-hoc evaluation** — a rationale  before the session, a narrative interpretation after. Binary success/fail  criteria are reserved only for genuinely measurable external milestones (a race  finish time, a swim-distance milestone) — not for "did this Tuesday easy run go  well."- **Tunable per-athlete thresholds** (HR-discipline %, EF stop-signal, jump-ratio  ceiling, the safety pattern above) are revised weekly by the LLM's own judgment  based on accumulating data, not hardcoded — stored versioned, with a rationale  attached to each revision.- **FIT files, not Strava's API streams, are the source of truth for pause/decoupling  accuracy.** Strava's API never exposes raw FIT event messages (timer stop/start) —  only its own pre-processed streams. This isn't a paid-tier limitation, it's  structural. Manual FIT upload for long/key sessions is the correct permanent  design, not a stopgap.- **Nutrition scope was deliberately cut** to just a carb-loading calculator before  long runs/races. Daily generic nutrition advice was scrapped — it was never  actually followed in practice.- **Readiness tracking was deliberately cut entirely** until a real HRV/sleep  tracker is bought (Fitbit Sense or a proper Garmin). Manual subjective check-ins  were miscalibrated and low-value. --- ## 3.
